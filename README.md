Run `npm run lint` to attempt to detect errors in your repository.

Use `output()` and `await input()` from `./src/js/scripts.js` to allow the user to interact with the console.
To run the console, launch `./src/index.html`.

Author: Jennifer-Rae Nielsen

Project Description
A simple object‑oriented program that simulates a car and its engine using two classes with constructors, default property initialization, and basic interactions.

Scope and Functionality
Implements Car and Engine classes.

Car: initializes odometer to 0 and creates its own Engine.

Engine: initializes running state to false.
Both classes accept other properties through constructor parameters.

Motivation
Created as part of an object‑oriented programming assignment.
